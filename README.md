## Getting Started

Follow the steps below to run the server and the frontend.

### 1. Start the server

In the root directory of the project, run the following command to start the backend server:

```bash
npm start
```
### 2. Start the Frontend server

In the root directory of the project go to my-app then, run the following command to start the backend server:

```bash
npm run dev
```
